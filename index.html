How to Block Ads, Step by Step

Do this in order. Setup takes only a few minutes.

01

Get Firefox

Firefox isn't perfect, but at least it won't lock you out for blocking ads like Chromium-based browsers do.

  1. Download it: mozilla.org/firefox
  2. Install it. Just click through.
  3. Launch it.
Enable IP Protection (50 GB/mo)

Firefox has a built-in proxy that hides your IP from trackers.

Free, 50 GB every month.

  1. Type about:config in the address bar and hit Enter.
  2. Click Accept the Risk and Continue.
  3. Search for browser.ipprotection.enabled.
  4. Click the toggle arrow or double-click it to switch to true.
02

Add uBlock Origin

The only extension you really need.

  1. Install from Add-ons Store
  2. Hit "Add to Firefox"
  3. It starts working immediately. Check your toolbar.

  2. Enable AdGuard URL Tracking Protection. Open the dashboard, go to Filter lists, expand Privacy and tick it.
  3. Import the Actually Legitimate URL Shortener Tool. It strips tracking junk out of links before the page even loads.
    • Go to Filter lists → Custom and tick Import.
    • Paste in the URL from the link above.
    • Click Apply changes.

Don't stack extensions

uBlock Origin with the lists from step 02 already covers what most other extensions promise. Every extra extension gets privileged access to your browser, means trusting one more developer, can make you easier to fingerprint, and can weaken Firefox's site isolation.

Skip the URL cleaners, cookie cleaners, local CDN hosts and extra tracker blockers. They mostly duplicate what Firefox and uBlock already do. Add something only when it fixes a problem you keep hitting.

DNS-Level Blocking

Everything above only cleans up the browser. Your phone, your apps and every other device still ask your ISP where every domain lives. Encrypted DNS fixes that with one setting.

01

Cloudflare 1.1.1.1

Fast, no account, nothing to log into. The plain resolver is below; the "Families" addresses also block malware (and adult content in the second one). All of it is encrypted.

DNS-over-HTTPS https://cloudflare-dns.com/dns-query
DoH (Families) https://security.cloudflare-dns.com/dns-query · https://family.cloudflare-dns.com/dns-query
DNS-over-TLS one.one.one.one
DoT (Families) security.cloudflare-dns.com · family.cloudflare-dns.com
IPv4 1.1.1.1 · 1.0.0.1
IPv6 2606:4700:4700::1111 · 2606:4700:4700::1001
Android — Private DNS (TLS)
  1. Settings → Network & internet (on Samsung: Connections).
  2. Tap Advanced → Private DNS.
  3. Choose Private DNS provider hostname.
  4. Enter one.one.one.one and hit Save.

Android only accepts a hostname here, not the https:// URL — this setting is DNS-over-TLS and covers Wi-Fi and mobile data at once.

iPhone / iPad

iOS has no DNS box to type into. Install the 1.1.1.1 app from the App Store — it drops in an encrypted DNS profile, and you can switch to the Families resolver in its settings.

Windows 11 (DoH)
  1. Settings → Network & internet → Wi-Fi (or Ethernet).
  2. Open Hardware properties (skip this on Ethernet).
  3. Click Edit next to DNS server assignment, then Manual.
  4. Turn on IPv4 and set Preferred DNS to 1.1.1.1.
  5. Set DNS over HTTPS to On (manual template) and enter https://cloudflare-dns.com/dns-query.
  6. Click Save.

In Firefox itself: Settings → Privacy & Security → DNS over HTTPS → Max Protection, then pick Custom and paste the same DoH address.

02

NextDNS

Filters per device with your own blocklists, query log and parental controls, and it works on every platform. Free for 300,000 queries a month, then $1.99/month if you blow past it.

Your ID is yours alone. There is no shared NextDNS address, so don't copy the ones below — sign in at nextdns.io and pull your endpoints from the Setup tab. A temporary account works for 7 days and only exists in that browser, so sign up free if you want your settings (and your filtering) to stick around.

DNS-over-TLS/QUIC <your-id>.dns.nextdns.io
DNS-over-HTTPS https://dns.nextdns.io/<your-id>
IPv6 2a07:a8c0::… · 2a07:a8c1::…
Linked IP 45.90.28.x · 45.90.30.x

The IPv6 pair and the linked-IP servers are per-profile, so take the exact values from your dashboard. Linked IP is plain DNS with no encryption — fine on a home router, not recommended on a phone.

Android
  1. Settings → Network & internet → Advanced → Private DNS.
  2. Pick Private DNS provider hostname.
  3. Enter <your-id>.dns.nextdns.io and save.

The NextDNS app for Android does the same thing and can also turn on per-app filtering, but Private DNS is enough for most people.

iPhone / iPad

Don't type the server by hand — grab the configuration profile at apple.nextdns.io and install it (Settings → Profile Downloaded). It sets encrypted DNS the native way. The NextDNS app from the App Store is the alternative.

Windows 11 (DoH)

Same screen as the Cloudflare steps above. Preferred DNS stays 45.90.28.0 and the DNS over HTTPS template becomes https://dns.nextdns.io/<your-id>. Your dashboard prints exact instructions for this too.

Phones in one line: Android takes the hostname ( *.dns.nextdns.io or one.one.one.one) in Private DNS; iPhone needs a profile or an app. The https:// form is for browsers and Windows 11. Only pick one resolver — stacking NextDNS on top of Cloudflare leaves you with neither.

Frequently Asked Questions

Short answers, with the step that covers each one.

What is the best ad blocker?

uBlock Origin. Free, open source, lighter than the alternatives, and its filter lists handle ads and trackers together. Install from step 02.

Does blocking ads break websites?

Rarely. uBlock's Easy mode is the default and breaks almost nothing. If a site misbehaves, click the uBlock icon and turn blocking off for that site only — step 05 covers it.

Do I need a script manager?

Only if you want to run userscripts like the link bypasser. Violentmonkey is the pick in step 03; if you install no scripts, skip it entirely.

Is all of this free?

Yes. Every browser tool here is free and open source. NextDNS is free for 300,000 queries a month, then $1.99/month — details in the DNS section.

What is DNS over HTTPS and should I use it?

It encrypts the lookups that turn domain names into addresses. Set at the device level with Cloudflare 1.1.1.1 or NextDNS, it also covers apps and other browsers that an extension can't reach. Only run one resolver.

Does this work on Chrome, Android or iPhone?

This guide targets Firefox. Firefox on Android supports uBlock Origin. Chrome's full uBlock Origin was disabled by Manifest V3, leaving the reduced uBO Lite. On iPhone, use a Safari content blocker instead.

Do I need both Cloudflare and NextDNS?

No. Pick one. Cloudflare needs no account and is the simplest; NextDNS adds per-profile filtering, logs and parental controls.
